# Sukanya Sahoo — Portfolio Website

A personalized single-page software engineer / AI engineer portfolio built from the original template while retaining its monochrome visual system, rounded cards, Poppins typography, and responsive navigation.

## Run locally

Open `index.html` directly in a browser, or run a small local server from this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Before publishing

The contact details in `cv.md` were used exactly as provided. Replace these placeholders when ready:

- `abc@gmail.com`
- `(111)-111-1111`
- `https://linkedin.com/in/your-profile`
- `https://github.com/abc`

Project cards intentionally do not claim repository or demo URLs that were not provided. Update the cards in `index.html` with specific links when available.

## Main files

- `index.html` — page content and sections
- `style.css` — desktop and shared styling
- `mediaqueries.css` — responsive styling
- `script.js` — mobile navigation and current year
- `cv.md` — downloadable CV
- `assets/*.svg` — custom technical illustrations, including the visual experience cards
